The first reference workflow

Start small.
Make the result visible.

The included Python task-list fixture gives the team a concrete maintenance issue, without connecting your business or client files.

  • Add an open / done / all status filter.
  • Preserve order and handle invalid input.
  • Review the diff and rerun fixed tests.

This example is a starting exercise. Its tests do not verify arbitrary repositories.
